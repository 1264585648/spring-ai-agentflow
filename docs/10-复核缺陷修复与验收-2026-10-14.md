## 运行方式变化

默认 API 要求宿主认证的 Principal；没有认证返回 401，没有 WebAccessPolicy 返回 403。X-User-Id 和 X-Forwarded-For 不构成身份或权限。

本机演示显式使用：

```bash
mvn spring-boot:run -Dspring-boot.run.profiles=demo
```

该 profile 绑定 127.0.0.1，允许本机匿名 Mock 演示并关闭真实写操作。只连接演示数据库，不通过反向代理向公网或其他用户转发；代理的本机来源不是最终用户身份。

真实部署还需宿主实现 WebAccessPolicy 的租户、会话与管理权限校验，以及独立 ActionAuthorizer 写授权。real-writes-enabled=true 本身不构成授权，也不能替代持久执行记录和结果核查。

## 尚未关闭的边界

这不是 F01–F18 全部关闭。F12 的 core→Web/infra 依赖、完整 DAG/插件生命周期、等待人工后原回合续跑仍待架构阶段。F15 已有默认拒绝和授权扩展点，但未接用户公司的 SSO、租户目录和资源权限数据。

F11/F13 仍为单 JVM 状态，没有持久审批/执行账本、进程重启恢复或未知结果人工核查工作流。未知记录不自动删除会消耗容量，满容量时拒绝新提案。F14 的实际 worker 取消已测试，但不能强制停止不合作的第三方 I/O；适配器仍需自己的超时。

F05 的演示动作选择与咨询意图识别仍需完善。F09 的空工具清单与继承默认语义、厂商模型可用性检查仍需收紧。F06/F18 的异常索引元数据、历史来源与真实 MySQL 初始化/升级尚需环境验证。SSE 不具备持久断点回放，前端构建/协议单测也不等于浏览器端到端验收。
