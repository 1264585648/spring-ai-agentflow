## 📖 项目介绍

这是一个基于 **Java 21 + Spring Boot 4 + Spring AI 2.0** 与 **React 18 + TypeScript + Vite** 构建的通用企业级多智能体开发底座。

它专注于解决企业大模型落地时共性的底层工程痛点：
1. **流式交互与状态机**：基于 SSE 统一管理思考过程（`thinking`）、步骤进度（`progress`）、打字机文字块（`message`）与结束信号（`done`）。
2. **人机协同（Human-in-the-loop）**：卡片驱动（Card-driven）协议，大模型给出决策方案，人类核验微调后一键提单，杜绝大模型直接写接口引发的失控幻觉。
3. **三级意图降级**：L1 规则匹配 (<30ms) ➔ L2 向量检索 (<100ms) ➔ L3 LLM 兜底，兼顾响应极致时延与调用成本。
4. **插座与插头（SPI 架构）**：框架只定协议，业务（客户服务、BPM审批、IT运维等）作为插件实现注入，业务与框架物理隔离。

## 💡 开发工作流与知识沉淀原则

> **小步慢跑，单一职责，每步必出知识卡片**：  
> 每次推进一个功能小步（如意图降级、熔断治理、卡片协议、提示词工程），必须严格做到：  
> 1. **一次只做一件事**：坚决杜绝大而全的无序堆砌，确保每个改动都能被清晰理解与验证；  
> 2. **同步产出 1~2 篇专栏卡片**：将设计背后的“为什么这样选型、有哪些替代方案、踩了什么坑”及时沉淀到 `docs/handbook/` 中，形成开源配套的高质量架构避坑专栏。
